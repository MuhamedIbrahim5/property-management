## 🎯 نظرة عامة

نظام شامل لإدارة العقارات والوحدات السكنية/التجارية ومتابعة بلاغات الصيانة من لحظة الإبلاغ حتى الإغلاق، مع توفير واجهة للموظفين والمستأجرين للتواصل وتتبع حالة الطلبات.

### الأهداف الرئيسية:
- ✅ تبسيط إدارة الصيانة وتحويلها لنظام منظم
- ✅ تسهيل التواصل بين المستأجرين وإدارة الصيانة
- ✅ توفير الشفافية الكاملة لجميع الأطراف
- ✅ اتخاذ قرارات مبنية على بيانات دقيقة
- ✅ توفير الوقت والتوثيق الكامل

## ✨ المميزات

### 🎛️ لوحة التحكم
- إحصائيات حية ومباشرة
- بطاقات KPI (إجمالي البلاغات، المكتملة، قيد المتابعة، المؤجلة)
- رسوم بيانية تفاعلية (Bar Charts، Donut Charts)
- توزيع البلاغات حسب الحالة والنوع والموقع

### 🏢 إدارة العقارات والوحدات
- إضافة وتعديل وحذف العقارات والوحدات
- تصنيف حسب الأحياء والأنواع
- ربط الوحدات بالعقارات
- إنشاء QR Code لكل وحدة

### 🔧 إدارة بلاغات الصيانة
- نظام شامل للبلاغات مع أرقام تسلسلية
- رموز متابعة للمستأجرين
- بحث وفلترة متقدمة
- إسناد البلاغات للموظفين
- رفع مرفقات وصور
- سجل أنشطة كامل (Activity Timeline)

### 📱 نموذج طلب الصيانة العام
- رابط عام لا يحتاج تسجيل دخول
- واجهة بسيطة للمستأجرين
- دعم QR Code لكل وحدة
- رفع صور للمشاكل

### 💬 تكامل WhatsApp
- إرسال تفاصيل الطلب مباشرة
- رسالة منسقة ومنظمة
- يعمل على Mobile وDesktop

### 👥 إدارة المستخدمين والصلاحيات
- 5 أدوار: Admin, Manager, Technician, Receptionist, Viewer
- صلاحيات محددة لكل دور
- تفعيل/تعطيل المستخدمين

### ⚙️ نظام قابل للتخصيص
- إدارة حالات الصيانة من الإعدادات
- إدارة أنواع الصيانة
- تخصيص الألوان والأيقونات
- تخصيص رسالة WhatsApp

### 🎨 تصميم احترافي
- واجهة عربية RTL 100%
- تصميم Modern SaaS
- Responsive لجميع الأجهزة
- ألوان متناسقة ومريحة

## 🚀 التثبيت

### 1. تثبيت التبعيات
```bash
npm install
```

### 2. إعداد قاعدة البيانات
```bash
# إنشاء Prisma Client
npm run db:generate

# إنشاء الجداول
npm run db:push

# إضافة بيانات تجريبية
npm run db:seed
```

### 3. إعداد المتغيرات البيئية
```bash
# انسخ ملف .env.example إلى .env
cp .env.example .env

# عدّل القيم إذا لزم الأمر
```

## 📱 الصفحات الرئيسية

### للإدارة (تحتاج تسجيل دخول):
| المسار | الوصف |
|--------|-------|
| `/` أو `/login` | تسجيل الدخول |
| `/dashboard` | لوحة التحكم والإحصائيات |
| `/dashboard/properties` | إدارة العقارات |
| `/dashboard/units` | إدارة الوحدات |
| `/dashboard/maintenance` | بلاغات الصيانة |
| `/dashboard/users` | إدارة المستخدمين |
| `/dashboard/settings` | الإعدادات |

### للمستأجرين (عامة - بدون تسجيل):
| المسار | الوصف |
|--------|-------|
| `/request` | نموذج طلب الصيانة |
| `/request?property=XXX&unit=YYY` | طلب مع وحدة محددة (عبر QR Code) |
| `/track?id=XXX&code=YYY` | متابعة حالة البلاغ |

## 🛠️ التقنيات المستخدمة

### Frontend
- **Next.js 14** - React Framework مع App Router
- **React 18** - مكتبة واجهة المستخدم
- **TypeScript** - للأمان وجودة الكود
- **Tailwind CSS** - تصميم حديث ومرن
- **Lucide React** - أيقونات احترافية

### Backend
- **Next.js API Routes** - Backend API
- **Prisma ORM** - إدارة قاعدة البيانات
- **SQLite** - قاعدة بيانات محلية (قابلة للترقية لـ PostgreSQL)
- **NextAuth.js** - مصادقة وإدارة الجلسات
- **bcrypt** - تشفير كلمات المرور

### أدوات إضافية
- **QRCode** - إنشاء أكواد QR
- **date-fns** - معالجة التواريخ
- **Zod** - التحقق من البيانات

## 🌐 النشر

### النشر على Vercel (موصى به):

#### 1. إنشاء قاعدة بيانات PostgreSQL
```bash
# استخدم Neon.tech (مجاني)
https://console.neon.tech/signup
```

#### 2. ربط مع Vercel
```bash
# عبر GitHub
1. ارفع الكود على GitHub
2. ربط Repository مع Vercel
3. إضافة Environment Variables
4. النشر التلقائي
```

#### 3. Environment Variables المطلوبة
```env
DATABASE_URL=postgresql://...
NEXTAUTH_URL=https://your-domain.vercel.app
NEXTAUTH_SECRET=your-secret-key-change-this
NEXT_PUBLIC_APP_URL=https://your-domain.vercel.app
NEXT_PUBLIC_WHATSAPP_NUMBER=966501234567
```

### النشر على VPS:
راجع **دليل_التسليم.md** للتفاصيل الكاملة.
